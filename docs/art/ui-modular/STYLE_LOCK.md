# Style lock v0 — contrato e hipóteses

**Aprovado (produto):**
- **Cozy Illustrated Anime Café + Ornamental Visual Novel**, personagens anime 2D ilustrados sem quantização/pixelização.
- Restaurante com camadas/modularidade, legibilidade do piso e móveis interativos. UI ornamental pode ser mais rica que a UI de turno.
- GPT gera **peças visuais**; Unity constrói a interação e os dados. Transparência corrigida no Blender é válida.
- A imagem `style_anchor_reference.png` do ART-01D é **referência de atmosfera**, não algo para copiar literalmente ou converter para pixel art.
- Maids Walk já aprovadas são referências de identidade e fidelidade; **não** reprocessá-las para combinar com UI.
